# Institutional Flow Gold — Swaraj Algo

A responsive, static brand/vision website for Institutional Flow Gold EA on MetaTrader 5.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive dark/gold design
- `script.js` — mobile navigation and current year

## Before publishing
1. Replace `contact@swarajalgo.com` in `index.html` with your real business email.
2. Review the founder title and product wording to ensure they match your official details.
3. Add your official MQL5 product page URL if you want a direct product button.
4. Do not add unverified profit, win-rate, backtest or customer claims. If you publish performance data, include the testing period, broker, symbol, timeframe, modelling method and risk figures.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `institutional-flow-gold`.
2. Upload all four files to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.

## Publish on Render
1. Push this folder to a GitHub repository.
2. In Render, choose **New → Static Site** and connect the repository.
3. Set Branch to `main`, Build Command to blank, and Publish Directory to `.`.
4. Click **Create Static Site**. Render will provide a live URL and redeploy when you push changes.
